### 🚀 درباره من (About Me)

سلام! من **سینا شجاعیان** هستم، دانشجوی مهندسی کامپیوتر و توسعه‌دهنده نرم‌افزار.

- 🎓 **حوزه تمرکز:** توسعه Full-Stack، طراحی دیتابیس، سیستم‌های بازیابی اطلاعات (IR/RAG) و میکروکنترلرها
- 🛠️ **پشته فنی موردعلاقه:** Next.js, NestJS, TypeScript, Prisma, Python
- ⚡ **فعالیت‌ها:** تدریس، توسعه پروژه‌های مدرن وب و ساخت مدارات دیجیتال
